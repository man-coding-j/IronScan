# Security policy

Report security or privacy issues privately to the repository maintainers. Do not include participant data, raw tongue images, access tokens, laboratory reports, or identifying metadata in an issue, pull request, or log.

IronScan is a non-clinical research prototype. The iOS production path performs inference locally. Developer Mode debug uploads are optional, disabled by default, token-protected on LAN, and subject to retention limits.

Supported security fixes apply to the current default branch. Dependency and provenance workflows run on every pull request.
