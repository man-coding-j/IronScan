# Training reports

Store aggregate, de-identified evaluation reports only. Do not commit private datasets or participant-level laboratory reports.

`pallor-v0.1.0/evaluation_summary.json` records aggregate metrics for the visual `TonguePale` engineering fixture. The private checkpoint, full training history, and hashed split manifest remain outside the repository under `~/Documents/IronScanPrivate/TrainingArtifacts`.

`multi-label-v0.1.0/evaluation_summary.json` records aggregate metrics for five source-dataset visual annotations. It contains no image paths, participant groups, or private fixture identifiers.
