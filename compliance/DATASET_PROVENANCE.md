# Dataset provenance

No private dataset is committed. On 2026-07-16, the project owner stated that IronScan has permission to train on and transform the local TongueDX copy. The supporting license, consent scope, participant-group mapping, calibration provenance, and laboratory-label definitions still require a reviewed dataset card under `MLTraining/datasets/dataset_cards/` before a trained model can pass the deployment gate.

On 2026-07-20, the local `anemia_detection_eye_nail_tongue-main` copy was inspected. Its dataset README identifies the images as augmented prototype data generated from user-provided samples and states that hemoglobin values are proxy/simulated. The local copy contains no license file and its `labels.csv` is a Git LFS pointer rather than usable metadata. It is restricted to engineering-fixture review and excluded from deployable risk-model training or validation pending documented reuse permission and laboratory-backed provenance.

On 2026-07-20, local copies of `AIQuest_DATATHON` and `hemoglobin-deficiency-detection` were inspected. AIQuest documents an augmented conjunctiva workflow and contains result graphics but no tongue dataset. The hemoglobin repository contains conjunctiva images, diagrams, and two erythema/hemoglobin tables without tongue-image linkage. Neither source contributes tongue images to the master structural dataset.

On 2026-07-21, the multimodal ingestion audit inspected the local folders named `anemia_detection_eye_nail_tongue`, `anemia_detection_eye_nail_tongue-main`, `Anemia_detection`, `Detection-of-Anemia-Using-Conjuctiva-Images`, `anemia-detection`, `AIQuest_DATATHON`, and `IronScanPrivate/TongueDx2`. Only the first combined repository copies and TongueDX exposed class-organized dataset images. The other repositories contained code, notebooks, model assets, demonstrations, or result graphics and contributed no accepted samples after asset filtering. The two combined-repository folders appear to be duplicate clones and are content-deduplicated.

The audit records source classes as proxy labels and requires a permission reference before copying. TongueDX `TonguePale` is recorded as `visual_pallor_proxy_not_anemia_ground_truth`. External eye/nail/tongue folder classes are recorded as `source_repository_proxy_class`. A reviewed source license or permission artifact, reliable participant grouping, duplicate/conflict report, and dataset card are required before any multimodal package can advance beyond engineering-fixture status.

The corrected audit produced a local, uncommitted 5,580-image engineering dataset: 127 eye images, 175 nail images, and 5,278 tongue images. It excluded 613 exact duplicates, 106 same-class perceptual duplicates, eight samples involved in conflicting exact label/tissue duplicates, two samples involved in a conflicting perceptual-label duplicate, four diagram/result assets, and one file without explicit tissue/class context. Private participant groups and TongueDX path locators are pseudonymized before manifest output. These counts describe local proxy-class files only and are not a participant count or evidence of clinical validity.

For the explicitly enabled Conrad Challenge demo path, external eye and nail images without source participant metadata receive deterministic appearance-cluster groups before splitting. The `appearance-cluster-1.0.0` procedure combines normalized grayscale structure with RGB summary histograms and uses complete-linkage agglomerative clustering with cosine-distance threshold `0.08`, independently within each source and tissue. The 2026-07-21 local rebuild assigned 302 eye/nail images to 137 groups: 88 multi-image groups, 49 singleton groups, and a largest group of 16 images. Exact duplicates remain removed before clustering, and every cluster is kept wholly within one split.

Appearance clustering reduces leakage from close variants and likely augmentation families, but it cannot identify a person or establish participant independence. Different images of one participant may remain in separate clusters, and visually similar images from different participants may be combined. TongueDX continues to use its source-provided pseudonymized groups, and ungrouped external tongue rows remain excluded from training. Synthetic similarity grouping applied for educational prototyping. Not cleared for clinical validation.

On 2026-07-22, the local `Eyes-Defy-Anemia` copy was ingested without committing source images or laboratory values. Its Italy and India workbooks describe 218 source participants captured with a standardized Samsung S6 rig. One participant lacked a usable hemoglobin value and one lacked the selected palpebral image, leaving 216 training-eligible participants: 91 below and 125 at or above the adult sex-specific hemoglobin screening thresholds used by the source integration. Hemoglobin-only labels may support anemia screening; they do not independently establish iron-deficiency anemia.

Source participant-folder identifiers are pseudonymized before manifest output. Similarity clustering uses the clinical images as anchors and keeps related external variants in the same split group; 216 clinical images produced 173 disjoint split groups after similarity unions. Sixty-two malformed PNG containers were losslessly normalized only in the private derived dataset so they could satisfy the locked eight-bit Core ML input contract. Source files were not modified. The local dataset document requests scholarly citation and permits free use, but no standalone license file was found; deployment remains blocked pending human review of reuse terms, consent scope, cohort representativeness, and independent external validation.
